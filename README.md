# Starlog

사진과 짧은 메모를 바탕으로, 경험의 맥락은 살리고 필요한 정보는 출처로 확인해 네이버 블로그 게시용 초안을 만드는 로컬 AI 콘텐츠 스튜디오입니다.

완성된 글을 자동 게시하는 도구가 아니라, 사용자가 직접 검토하고 수정할 수 있는 **게시 전 초안 제작 도구**를 지향합니다.

## 가장 쉬운 실행 방법 — Windows

일반 사용자는 개발 도구나 명령어를 다룰 필요가 없습니다.

1. GitHub에서 **Code → Download ZIP**을 누릅니다.
2. 내려받은 ZIP 파일을 원하는 폴더에 **모두 압축 해제**합니다.
3. 프로젝트 폴더의 **`Starlog.exe`**를 더블클릭합니다.
4. 준비가 끝나면 브라우저에서 Starlog가 자동으로 열립니다.

`Starlog.exe`만 다른 위치로 옮기면 실행되지 않습니다. `app`, `components`, `launcher` 등의 폴더와 함께 있어야 합니다.

첫 실행에서는 프로젝트 전용 Node.js와 패키지를 자동으로 내려받기 때문에 인터넷 연결이 필요하며 다소 시간이 걸릴 수 있습니다. 이후 실행은 훨씬 빠릅니다. 별도의 서버 시작·중단 창은 표시되지 않습니다.

서명되지 않은 개인 개발용 EXE이므로 Windows가 처음 한 번 SmartScreen 안내를 표시할 수 있습니다. 경고 없이 배포하려면 배포자가 코드 서명 인증서로 EXE에 서명해야 합니다.

## 데모 먼저 보기

Codex 로그인 없이도 화면 구성과 결과물을 확인할 수 있습니다.

1. `Starlog.exe`로 프로젝트를 실행합니다.
2. 상단의 **예시 불러오기** 또는 결과 영역의 **완성된 예시 먼저 보기**를 누릅니다.
3. 가상의 호수공원 기록, 샘플 이미지 3장, 완성 초안, SEO 점검과 썸네일이 한 번에 표시됩니다.

내장 예시는 UI 시연을 위해 만든 가상 콘텐츠입니다. 실제 장소 정보나 검색 결과가 아니며, 샘플 이미지는 브라우저가 직접 그리는 데모용 일러스트입니다.

### 예시 입력

| 항목 | 예시 |
| --- | --- |
| 주제 | 초여름 호수공원 산책 후기 |
| 목적 | 방문 경험 |
| 독자 | 조용한 산책 장소를 찾는 독자 |
| 핵심 키워드 | 호수공원 산책 |
| 메모 | 도착 시간, 걸었던 동선, 기억에 남은 노을과 개인적인 감상 |

### 예시 결과

- 제목: `초여름 호수공원 산책, 노을이 좋았던 조용한 오후`
- 세 개의 본문 섹션과 사진 배치·캡션
- 수정 가능한 제목·본문·해시태그
- SEO 점검과 키워드 사용 현황
- 1080×1080 JPG 썸네일 미리보기 및 저장
- 네이버 블로그 에디터에 붙여넣기 쉬운 UTF-8 TXT 저장

## 주요 기능

- JPG, PNG, WebP, HEIC/HEIF 사진 최대 100장 업로드 및 브라우저 압축
- 사진 순서와 장면을 반영한 제목·본문·캡션·대체 텍스트 생성
- Codex CLI 웹 검색을 이용한 최신 공식 정보 확인과 출처 정리
- 콘텐츠 목적, 핵심 독자, 문체와 마무리 행동 설정
- 제목·본문·사진 설명·해시태그 직접 수정 및 자연어 재작성
- 프로젝트 문체 자료실을 통한 기존 글의 스타일 반영
- 입력 자동 저장, 완성 초안·사진·썸네일 저장 및 불러오기
- 대표 사진 1장 또는 비대칭 3장 콜라주 썸네일 제작
- SEO·팩트체크 점검과 네이버용 TXT 다운로드

## 일반 사용자 요구 사항

- Windows 10/11
- 첫 실행 시 인터넷 연결
- 실제 AI 초안 생성 시 OpenAI Codex CLI와 ChatGPT 로그인

Node.js와 프로젝트 패키지는 EXE가 프로젝트 내부에 자동으로 준비합니다. 내장 데모 예시를 보는 데는 Codex 설치나 로그인이 필요하지 않습니다.

## 개발자용 실행

소스 코드를 수정하거나 다른 운영체제에서 실행하려면 Node.js 20.9 이상을 준비합니다.

```bash
git clone <YOUR_REPOSITORY_URL>
cd Starlog-Public-Demo
npm ci
npm run dev
```

브라우저에서 [http://127.0.0.1:3000](http://127.0.0.1:3000)을 엽니다.

프로덕션 빌드는 다음과 같이 확인합니다.

```bash
npm run lint
npm run build
npm start
```

## 실제 AI 생성 준비

Codex CLI의 로그인 상태를 확인합니다.

```bash
codex login status
```

로그인되어 있지 않다면 다음 명령을 실행합니다.

```bash
codex login
```

대부분 별도 API 키나 `.env.local`은 필요하지 않습니다. Codex 실행 파일을 자동으로 찾지 못할 때만 `.env.example`을 참고해 `CODEX_CLI_PATH`를 설정하세요.

## Windows용 실행 파일 다시 만들기

저장소에는 바로 실행할 수 있는 `Starlog.exe`가 포함되어 있습니다. 실행기 소스를 수정했다면 PowerShell에서 다음 명령으로 다시 빌드할 수 있습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\launcher\build.ps1
```

생성된 `Starlog.exe`를 더블클릭하면 필요한 로컬 도구와 의존성을 준비하고 서버를 백그라운드에서 실행한 뒤 브라우저를 엽니다. GitHub Releases에는 저장소 전체를 ZIP으로 묶어 제공해야 하며 EXE만 단독으로 배포해서는 안 됩니다.

## 데이터와 개인정보

Starlog는 다음 데이터를 프로젝트 내부의 `.starlog-data`에 저장합니다.

- `drafts`: 저장한 초안, 브리프와 압축 사진
- `writing-library`: 문체 분석용 PDF·TXT·Markdown·HTML
- `settings.json`: 초안 및 썸네일 작성 지침

`.starlog-data`, `.local-tools`, `.next`, `node_modules`와 환경 변수 파일은 Git에서 제외됩니다. 저장소를 공개하기 전에 다음 명령으로 추적 대상에 개인 파일이 없는지 확인하세요.

```bash
git status --short
git ls-files
```

사진에는 얼굴, 차량번호, 주소, 예약 정보 등이 포함될 수 있습니다. 공개 저장소에 실제 사용자 사진이나 저장 초안을 예제 파일로 넣지 마세요.

## 동작 흐름

```text
사진·메모 입력
      ↓
브라우저 이미지 압축
      ↓
Codex CLI 사진 분석·웹 검색
      ↓
구조화된 초안·출처·SEO 결과
      ↓
사용자 수정·저장·네이버용 다운로드
```

서버는 생성 작업마다 임시 디렉터리를 만들고, 성공 여부와 관계없이 임시 사진과 결과 파일을 삭제합니다. Codex는 읽기 전용의 임시 세션으로 실행됩니다.

## 프로젝트 구조

```text
app/                 Next.js 화면과 API 라우트
components/          입력, 결과, 썸네일과 설정 UI
lib/                 Codex 실행, 이미지, 저장소와 타입
launcher/            Windows 무창 실행기 소스
lib/demo.ts          로그인 없이 확인하는 내장 예시
```

## 배포 참고

이 프로젝트는 Codex CLI 실행과 로컬 파일 저장을 사용하므로 개인 PC의 로컬 서버 실행을 전제로 합니다. 소스 코드를 GitHub에 공개하는 것과 서비스를 인터넷에 그대로 배포하는 것은 다릅니다. 서버리스 호스팅에 배포하려면 인증, 저장소, 실행 격리와 업로드 보안을 별도로 설계해야 합니다.

## 한계

- 생성 결과와 출처는 게시 전 사람이 반드시 확인해야 합니다.
- 검색 순위나 네이버 상위 노출을 보장하지 않습니다.
- 이미지로만 이루어진 PDF에는 OCR을 적용하지 않습니다.
- Codex 사용량은 연결된 ChatGPT 플랜의 한도를 사용합니다.
